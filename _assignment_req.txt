1. Assignment Scenario
You are working as a junior data engineer in a recruitment analytics company. The company wants to monitor AI, machine learning, data science, data analytics, data engineering, and BI jobs from multiple online job sources.
Manual job monitoring is slow and inconsistent because each website has different fields, data quality, job descriptions, and salary formats. Your task is to design and implement an automated job market analytics pipeline that extracts job data, standardizes it, filters relevant jobs, performs cleaning, calculates business metrics, and sends an automated notification or summary.
Important Scope
The final cleaned dataset must contain only AI/ML/Data-related jobs.
The project is not only about collecting data. The main learning outcome is to convert messy multi-source job data into a clean, validated, analytics-ready dataset.

6. Extraction Requirements
Students must create an extraction process for each required source. They may use Python, HTTP requests, API clients, or another appropriate method. The important requirement is that the extracted raw data is reproducible and saved before cleaning.
Each source must produce a separate raw file before merging.
Each raw file must include the source name and scrape/extraction date.
The extraction process must not require paid API keys.
The extraction process must be respectful: avoid excessive requests, use pagination carefully, and do not overload public services.
Students must not use websites that require login, account scraping, CAPTCHA bypassing, or prohibited automation.
If a source is temporarily unavailable, students may replace it with a backup source and explain the reason in the report.

9. Salary Extraction and USD Conversion Requirement
Salary analysis is mandatory. Students must attempt to extract salary information from structured salary fields and from salary text inside job descriptions. Salaries must be standardized into annual USD values.
If a source provides salary_min and salary_max, use those fields directly after cleaning.
If salary appears only in text, extract salary ranges from the description where possible.
Treat salary value 0 as missing, not as a real salary.
Do not include missing salary records in the average salary calculation.
Create salary_min_usd, salary_max_usd, and salary_mid_usd.
Average salary must be calculated using salary_mid_usd only where salary_mid_usd is not null.
Salary Case
Required Treatment
$85,000 - $95,000 a year
currency=USD, annual min=85000, annual max=95000
EUR 60,000 - 75,000
currency=EUR, convert annual salary to USD
£40k - £55k
currency=GBP, convert k values to full annual amount, then USD
$40/hour
convert hourly to annual using 40 hours/week x 52 weeks = 2080 hours
$5,000/month
convert monthly to annual using x12
salary_min=0 and salary_max=0
mark salary as missing
Recommended free exchange-rate API: Frankfurter API. Example pair endpoint format: https://api.frankfurter.dev/v2/rate/EUR/USD. Students may use another free, no-key exchange-rate source, but they must mention the API name, conversion date, and currency rates used.
salary_mid_raw = (salary_min_raw + salary_max_raw) / 2
annual_salary_raw = salary_mid_raw x period_factor
salary_mid_usd = annual_salary_raw x fx_rate_to_usd
average_salary_usd = AVG(salary_mid_usd) where salary_mid_usd is not null

11. KNIME Cleaning and Transformation Requirements
Students must use KNIME to clean and transform the merged dataset. The instructor should not prescribe the exact nodes. Students may choose any KNIME nodes, components, or workflow design as long as the required outcomes are achieved.
Read the merged raw dataset from all selected sources.
Remove or fix HTML tags, special symbols, inconsistent spacing, and encoding issues in descriptions.
Standardize title, company name, location, job type, and date columns.
Deduplicate jobs using job_url when available; otherwise use a combination of title, company, source, and location.
Apply the mandatory AI/ML/Data relevance filter.
Extract and standardize important skills from title, tags, and description.
Create a clean job category column such as Data Analytics, Data Engineering, Data Science, AI/ML, BI, Analytics Engineering, or Other Data.
Standardize remote_status into Remote, On-site, Hybrid, or Unknown.
Extract experience years and create experience_bracket.
Extract salary, normalize pay period, convert currencies, and create USD salary fields.
Create final clean CSV file and summary metrics file.
No Required KNIME Node List
Students are free to choose the KNIME nodes and methods. The grading will be based on correctness of output, workflow clarity, validation, and explanation, not on using a specific node name.


12. Airflow DAG Requirements
Students must create one Apache Airflow DAG that orchestrates the full workflow. The DAG should contain multiple tasks, not separate DAGs for each step.
Task
Purpose
extract_arbeitnow
Collect raw data from Arbeitnow
extract_remoteok
Collect raw data from RemoteOK
extract_himalayas
Collect raw data from Himalayas
extract_remotejobs
Collect raw data from RemoteJobs.org
merge_sources
Standardize schemas and merge all raw datasets
run_knime_workflow
Execute the KNIME workflow that cleans and transforms data
validate_clean_output
Check row counts, columns, missing values, duplicates, and output existence
calculate_metrics
Generate final analysis metrics for report and notification
trigger_n8n_workflow
Send metrics/notification to n8n webhook
archive_outputs
Save timestamped raw and cleaned output files
The four extraction tasks can run in parallel because they do not depend on each other. The merge task should run only after all extraction tasks are complete.
13. n8n Automation Requirements
Students must create an n8n workflow that is triggered after the clean output and metrics are generated. The n8n workflow may send an email, update Google Sheets, post to Slack/Discord/Telegram, or call another webhook.
The n8n notification must include total cleaned AI/ML/Data jobs.
It must include jobs by source.
It must include the remote/on-site/hybrid ratio.
It must include count of 0-1 year jobs.
It must include average salary in USD where salary is available.
It must include pipeline run status: Success or Failed.
